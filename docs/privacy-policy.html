Seerr Selection Search

Privacy Policy

Last updated August 21, 2026

The short version

This extension does not collect, transmit, or sell any of your data to its developer or to any third party. The only network requests it ever makes are to the one Seerr server address you configure yourself, and only when you actively search.

What the extension stores

Two values you enter on the extension's own Options page:

ValuePurposeWhere it lives
Seerr URLThe address of your self-hosted Seerr instancechrome.storage.local — this device only
Seerr API keyAuthenticates search requests to your Seerr instancechrome.storage.local — this device only

Both are stored in chrome.storage.local, never chrome.storage.sync — they stay on your device and are never attached to your Google account or synced anywhere.

What the extension sends, and to whom

When you highlight text and choose Search Seerr from the right-click menu, the extension sends that selected text to the single Seerr origin you configured, as a search request. That request also carries your API key, exactly as it would if you typed the search into Seerr's own web page.

Nothing is ever sent to the extension's developer, to an analytics service, or to any server other than the Seerr instance you specified. There are no third parties in this data path at all.

Page access

The extension does not run scripts on the pages you visit and cannot read their content. It has no content script and no <all_urls> permission. Its only two capabilities are: adding one item to the right-click menu, and — only for the single origin you explicitly grant — talking to your Seerr server when you trigger a search.

Your control

  • Clearing the URL and API key fields in Options and saving removes them from local storage.
  • Uninstalling the extension removes all locally stored data with it.
  • Revoking the extension's host permission for your Seerr origin (via Chrome's extension settings) stops it from making any network request at all.

Changes to this policy

If this policy changes, the "Last updated" date above will change with it. Material changes will also be reflected in the Chrome Web Store listing.

Seerr Selection Search is an independent, unofficial companion extension. It is not made by, affiliated with, or endorsed by the Seerr project.
